   Tests CRC16-CCITT with known vector "123456789" = 0x31C3

4. test_crc16_incremental_consistency
   Tests combined data produces different CRC than individual parts

5. test_crc16_different_data_different_crc
   Tests different data produces different CRCs

6. test_crc16_large_data
   Tests CRC handles 4KB data without errors

Statistics Tests (2)
─────────────────────────────────────────────────────────────────────────────
7. test_stats_reset
   Tests statistics reset clears all counters

8. test_stats_null_pointer
   Tests NULL stats pointer returns ESP_ERR_INVALID_ARG

Packet Structure Tests (9)
─────────────────────────────────────────────────────────────────────────────
9. test_packet_header_size
   Tests header is exactly 16 bytes

10. test_packet_header_initialization
    Tests all header fields can be set correctly

11. test_packet_types_defined
    Tests all 5 packet types have correct values:
    - IPC_PACKET_TYPE_VIDEO = 0x01
    - IPC_PACKET_TYPE_CONFIG = 0x02
    - IPC_PACKET_TYPE_TELEMETRY = 0x03
    - IPC_PACKET_TYPE_STATS = 0x04
    - IPC_PACKET_TYPE_CONTROL = 0x05

12. test_packet_flags_defined
    Tests all 4 flags are bitwise distinct:
    - IPC_FLAG_PRIORITY = 0x01
    - IPC_FLAG_FRAGMENTED = 0x02
    - IPC_FLAG_LAST_FRAGMENT = 0x04
    - IPC_FLAG_REQUIRES_ACK = 0x08

13. test_sync_bytes_defined
    Tests sync bytes are 0xAA and 0x55

14. test_video_payload_structure
    Tests video payload fields accessible

15. test_config_payload_structure
    Tests config payload fields accessible

16. test_crc_packet_validation
    Tests CRC calculation matches re-verification in packet context

17. test_sync_byte_detection
    Tests sync bytes can be detected in buffer
